# Flowey 🎯
> An Enterprise-Grade Agile Project Management Platform (Jira Clone)
 
Flowey is a modern, high-performance issue tracking and project management tool designed for agile teams. Built with a focus on real-time collaboration, scalability, and robust architecture, it seamlessly handles complex workflows, ticket management, and team coordination.
 
---

## 🚀 Key Features
 
- **Real-Time Board Synchronization:** Kanban boards update instantly across all connected clients using SignalR, ensuring the whole team is always on the same page.
- **CQRS & Clean Architecture:** Strongly decoupled layers ensuring high testability, maintainability, and separation of concerns.
- **File & Media Management:** Integrated with Cloudinary for scalable image and file uploads, with optimized delivery.
- **Payment & Subscription System:** Stripe integration for plan-based subscriptions and secure payment processing.
- **Interactive UI:** A highly responsive, component-driven frontend built with React for a flawless user experience.

---
 
## 🛠️ Technology Stack
 
### Backend (Core API)
| Technology | Purpose |
|---|---|
| .NET 8 / ASP.NET Core Web API | Core backend framework |
| Clean Architecture + CQRS | Architectural pattern |
| MediatR | Command/Query handling |
| SignalR | Real-time WebSocket communication |
| Entity Framework Core | ORM & data access |
| Stripe | Payment & subscription processing |
| Cloudinary | Cloud-based media & file management |
 
### Data & Infrastructure
| Technology | Purpose |
|---|---|
| PostgreSQL | Primary relational database |
 
### Frontend
| Technology | Purpose |
|---|---|
| React | UI library |
| Redux Toolkit | State management |
| React Router | Client-side routing |
| SignalR Client | Real-time board updates |
